## 시놉시스
<i><b>아무도 오지 않는 숲 속에 카페를 차린 주인공. 그곳은 특이한 음료를 판매하는 카페였는데… 특이한 음료를 원하는 특이한 손님들이 카페를 찾아온다. 카페에 찾아온 손님에게 음료를 판매하며 최종 레시피를 얻어보자!</i></b>

<br><br>

## 목표
단기 목표: 손님 주문 처리하기, 퀘스트 클리어하기, 재료 구매하기
최종 목표: 최종 레시피 조각을 모두 모아 최종 ‘코스믹 블룸’ 레시피를 해금하기

<br>

최종 레시피를 얻은 주인공은 목표를 달성하여 엔딩. 
플레이 점수를 계산하여 S(~90점), A(~80점), B(~70점), C(70 미만)로 등급이 나온다.
게임은 여기서 끝이지만, 계속해서 음료를 판매할 수 있다.

<br><br>

## 내가 담당한 역할
팀 내에서 프로그래밍을 맡아 NPC 주문 처리 시스템과 주문서 UI를 구현했습니다. 또한 재료 구매 UI와 재료 데이터를 ScriptableObject로 관리해, 구매 시 재료 수량과 소지 금액이 실시간으로 반영되도록 구현했습니다. 이와 함께 완성된 음료를 클릭하면 플레이어에게 부착되고, 이를 손님에게 전달하는 상호작용 로직을 담당했으며, 플레이어 이동과 오브젝트 충돌 처리도 구현했습니다.
